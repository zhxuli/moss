moss · 使用说明
==================================================

一句话：你不装功能 —— 你告诉它缺什么，它当场长出来。
（一个 7 MB 的宿主，加上住在里面的 AI。）

--------------------------------------------------
一、三步上手
--------------------------------------------------

1) 解压到一个**固定的文件夹**，比如  D:\Tools\moss
   · 别放桌面 / 下载目录：以后升级是整包覆盖，这两处容易被清理工具扫掉。
   · 别放 C:\Program Files —— 它要往自己目录里写 user_data，那里没权限。

2) 双击 moss.exe
   · 第一次打开会自己在同目录建 user_data\（你的包、技能、配置、运行记录都在这儿）。
   · 想在命令行先体检一遍：  moss.exe --selfcheck

3) 想用 AI 的话，填一次配置
   · 界面里 设置 → AI：填接口地址（base_url）、Key、模型名。
   · 你自己的 Key，直连你自己的账号，不经过我们。

--------------------------------------------------
二、目录里有什么
--------------------------------------------------

  moss.exe          宿主内核（解析命令行、找解释器、装包、开界面）
  system\           发行目录：界面、15 个出厂包、插件契约、技能手册、自带 Python
  user_data\        你的地盘（第一次运行才出现）：
                      pkgs\      你自己装的包
                      state\     各包的运行数据、AI 会话记录
                      backups\   版本快照（改坏了能退回）
                      config.toml 设置
  使用说明.txt       就是本文件

想搬家 / 备份：**整个文件夹拷走就行**，路径不写进注册表。

--------------------------------------------------
三、常用命令（也可以全在界面里点）
--------------------------------------------------

  moss                       用法 + 包列表
  moss ui                    打开界面（包列表 / 内嵌标签 / 文件管理 / AI 工作台）
  moss :<包名> [参数]         跑一个装好的包，例如  moss :md5 你好
  moss --selfcheck           自检：路径、运行时、包都对不对
  moss --snap list           看有哪些版本快照
  moss --snap revert :<包> <快照id> --yes    回到某个时间点

把 moss 加进系统 PATH（设置 → 命令接入）之后，任何终端、任何目录都能直接敲 moss。

--------------------------------------------------
四、常见问题
--------------------------------------------------

问：要装 Python 吗？
答：不用。自带 Python 3.12（system\runtimes\python），包不依赖你机器上的 Python。

问：Windows 提示"未知发布者"怎么办？
答：没有代码签名。点「更多信息」→「仍要运行」即可。它不联网*（AI 功能除外：那部分只连你自己
    配的模型接口），不写注册表、不写系统目录。

问：升级会不会弄丢我的东西？
答：不会。升级只覆盖 moss.exe 和 system\，user_data\ 一个字都不动。

问：AI 会不会乱改我的东西？
答：· 每次动手改文件之前，宿主先存一条"动手前"的版本快照，改坏了能一键退回；
    · 它能读写哪些目录是一张清单（每行一对「读 / 写」勾），没勾的地方读都读不了；
    · core\、moss.exe、venv\、.git\、备份库是硬锁，勾了"任意路径"也写不了；
    · 它自己新造的工具（技能）要你点一次「允许」，下一次开工才带上。

问：会不会很占地方 / 很慢？
答：内核 7 MB；整个发行包解压后约 250 MB（大头是自带的 Python 运行时）。

--------------------------------------------------
五、还没到 1.0
--------------------------------------------------
插件契约（spec 1）还会动。遇到问题、想要个新包，直接在它里面说一句就行 ——
它读契约、写代码、跑一遍验证，然后交给你验收。
