# shot —— 截屏（AI 自己的手）

**什么时候用它**：要给用户**留个证据**（"改完了，你看这界面"）、或者要一眼看清某个窗口现在
长什么样的时候。AI 自己**看不到图** —— 这条路是"截下来给用户看"，不是"让 AI 看图"。

## 怎么调

AI（工具表里就有，参数带类型）：

```
shot(target="记事本")      只截标题里带"记事本"的那个窗口
shot()                     截整个屏幕（多屏会拼在一起）
shot(out="D:\\tmp\\a.png")  指定存哪儿
```

人 / 命令行（跟 AI 走的是同一条路）：

```
moss :skill run shot target=记事本
moss :skill doc shot          ← 就是这一份说明
```

## 它会怎么回话

```
整个屏幕 截下来了：D:\python\two\moss\user_data\state\shot\shots\shot-20261005-181500.png（7680×2160，8782372 字节）
（我看不到图 —— 这是留证据给用户看的；要看像素请自己用 PIL 量。）
```

* 找**不**到那个窗口时：**把现在开着的窗口标题列出来**（这样你下一轮不用再猜）。
* 存哪儿：不填就落在 `MOSS_PLUGIN_DATA_DIR/shots/`（= `user_data/state/shot/shots/`）。
* 想再看像素：`out` 存下来之后自己用 `PIL` 读（它就在自带运行时里）。
