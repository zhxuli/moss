========================================
 EdgePaste 贴边快输 · 分组版 v3  (pa soft 插件)
========================================

启动方式:
  pa :edgepaste

---------------- 分组 (纵向列表, 像 QQ 分组) ----------------
  标题条长这样:   [┃] [▼] [☑] 分组名 ....... Ctrl+Alt+1  3 条  ＋
    ┃  当前操作的分组(left 蓝色竖条)
    ▼  展开/折叠三角 (点它或点标题)
    ☑  "生效"复选框 —— 这就是开关
    ＋  在本分组新增一个条目

  · ☑ 勾选/取消 = 让这个分组生效 / 停用 (可同时勾多个, 互不影响)
      生效中的分组是蓝色高亮: 蓝底 + 蓝描边 + 名称变蓝, 组内条目也是蓝描边
      **不同分组可以用完全相同的热键** —— 只有勾选生效的分组才注册热键
  · 点标题 / 点三角 = 展开或折叠, 只看显示, 绝不影响别的分组是否生效
  · 中键点标题 = 只勾选这一个分组 (其它分组的勾选全部清掉)
  · 没勾选的分组只是热键暂停, 条目照样能看能改能拖
  · 按住标题上下拖 = 调整分组顺序 (拖动时实时预览)
  · 双击标题 = 改名; 右键标题 = 启用/停用 / 复制 / 新增条目 / 上移下移 / 删除
  · 底部「＋ 新建分组」= 新建; 顶栏「分组」= 分组管理(改名/切换热键/排序/勾选生效)

  键盘切换分组 (给懒得点鼠标的时候):
    1. 给分组设一个"切换热键", 按了就切过去 (独占生效)
    2. 设置里给"上一个分组 / 下一个分组"各设一个热键, 循环切换

---------------- 条目 ----------------
  · 点分组标题右侧的 ＋ 新增: 新增后光标自动落到输入框, 直接打字即可
      (新增了却什么都没填就点别处 -> 这条空条目会自动取消, 不留垃圾)
  · 备注 (可选, 推荐给"过段时间就忘了是啥"的密钥写一句):
      条目右键 → 备注…  → 写一句说明 → 保存 (也可以留空/清除)
      平时完全不显示, 鼠标悬停在条目上时才在面板旁边弹一个小气泡
      有备注的条目右侧会有一个小小的「注」字, 点它也能直接编辑
  · 按住条目左边的 ≡ 拖动 = 拖到别的分组, 或调整组内顺序
      (拖动时显示蓝色落点线; 拖到没生效的分组会自动勾选生效)
  · 悬停在快捷键标签上直接按键 = 录制快捷键 (录制时会挂起全局热键, 不怕被系统拦截)
  · 单击快捷键标签 = 复制到剪贴板
  · 鼠标悬停条目 → 点右侧 ✕ 删除
  · 条目右键 = 备注 / 移动到其它分组 / 复制 / 删除
  · 标签显示: 蓝色=已生效, 灰=未设或该组未生效, 红「⚠冲突」=被别的程序占用,
              橙「⚠格式」=写法不对 (例: F4 / Ctrl+Alt+1)

---------------- 窗口 ----------------
  · 顶栏可自由拖拽, 靠近屏幕边缘松手 → 自动吸附并隐藏成小边条
  · 鼠标移到该屏幕边缘 → 面板自动滑出
  · 拖到屏幕中间松手 → 常驻悬浮
  · 鼠标放在窗口最左/最右边框 → 可拖拽调整宽度
  · 顶栏右键 = 新建分组 / 分组管理 / 设置 / 帮助 / 退出

---------------- 其它 ----------------
  · 总开关热键: 默认 Ctrl+Alt+E 显示/隐藏整个面板 (设置里可改)
  · 设置里可以关掉"列出未生效的分组", 列表就只留勾选生效的那些
  · 单实例: 再次运行 pa :edgepaste 会把已运行的面板唤出, 不会开两个

配置文件: user_data\paste\data.json   (自动保存)
          数据目录由宿主 pa 通过环境变量 PA_PLUGIN_DATA_DIR 注入,
          不再写在插件自己的目录里(升级/重装不会丢数据)。
          旧版(单层条目)第一次启动会自动迁移到「默认」分组,
          并把原文件备份成 data.json.v1.bak
出错日志: user_data\paste\error.log
          (独立运行插件、没经过 pa 时, 上面两处退回插件自身目录)
