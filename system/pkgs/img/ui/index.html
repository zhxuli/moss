命令行怎么用

      
同一个包，两种用法：不带参数就是打开这个界面，带上参数就走命令行。

      

      
界面里的操作

      
    
        
  • 拖放：文件夹或图片拖到中间那块 → 设为「源」；文件夹拖到「保存」行右边那格 → 设为输出目录
    • 
        
  • 选择：单击选中 · Ctrl+单击加选/取消 · Shift+单击连选一段 · 空白处按住拖 = 框选
    • 
        
  • 双击缩略图 = 用系统默认程序打开它
    • 
        
  • 快捷键：Ctrl+A 全选 · Esc 清除选择 · Delete 从文件清单去掉 · Ctrl+R 刷新 · Ctrl+Enter 开始处理
    • 
        
  • 不选 = 全部处理；选了就只处理选中的那几个
