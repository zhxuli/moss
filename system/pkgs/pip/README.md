# Pip 工具 · 怎么用

图形化的 **Python 包管理器**（窗口标题：`Python 库管理器 v14.3 - 交互增强版`），
管的是 **moss 自己那个 Python 环境**：`<moss 根>\venv`。

## 怎么打开

- 在左边列表里选它 → 点「运行」；或者双击那一行；等价于命令行 `moss :pip`。
- ★ **别直接双击 `main.exe`**：它靠 moss 启动时给的环境变量去找 Python 环境。
  自己双击会显示「未找到Python环境」，所有功能都禁用（状态栏写"环境错误，功能已禁用"）。
  用 `moss :pip` 起是好的，标题里会写 **`[管理: D:\…\moss\venv]`** —— 看到这一行就说明它认上了。

## 窗口里有什么

四个页签：

| 页签 | 干什么 |
|---|---|
| **库管理** | 看当前环境里装了哪些包（名字 / 版本 / 状态），对单个包做卸载、升级 |
| **查找新库** | 按名字搜 PyPI，选中后装进这个环境 |
| **交互式 Shell** | 在这个环境里直接敲命令（`pip list`、`python -V`、`pip install …` 都行） |
| **操作日志** | 每次装 / 卸 / 升级的**时间、操作、状态**一张表；下面那栏是完整输出，出错就看这儿 |

## 它动的是谁

- 它**不是**"随便挑个 Python 来装包"：它写的是 `D:\…\moss\venv` ——
  **moss 自己的界面和插件都跑在这个环境里**。
  所以：装包前想清楚（界面就依赖着它），也别在它跑着的时候再从命令行动同一个环境。
- 装完立刻生效：moss 的插件下次启动就能 `import` 到新包。

## 需要什么

- 能连 `pypi.org`（这个包的 `capabilities.net` 就声明了这一个）。
  国内下不动就在「交互式 Shell」里加镜像，例如：
  `pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple`
- 不需要管理员权限。

## 数据放哪

| 东西 | 位置 | 说明 |
|---|---|---|
| 它自己的记录 | `user_data\state\pip\` | 删掉不影响功能（只是历史没了） |
| 它管理的环境 | `<moss 根>\venv\` | **这个才是真身**，手删会把 moss 弄坏 |

## 已知限制

- 它是**交互式界面**，不是给 AI 调的工具（`ai.expose = false`）：没有 `action=…` 那种用法，
  `moss :pip` 只会把窗口开起来，关掉窗口就等于退出。
- 界面是 Tkinter 的老样式（从老项目整包移植，功能代码没重写，见 `AGENT.md` 的「来历」）。
- **不判重**：连点两次「运行」会开两个窗口，两个都在改同一个 venv。
- 包管理本身没有"撤销"：卸错了就重新装回来（它会记在操作日志里，能照着重装）。
