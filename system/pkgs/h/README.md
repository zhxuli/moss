# h —— 历史快捷运行

`moss --history` 的短名字：**敲得出名字，就直接切到那个目录再跑一次。**

```
moss :h                     列出最近跑过的（等于 moss --history）
moss :h zeen                找到上次在 ZeEn 目录里跑的那个程序，切过去再跑一次
moss :h z/m                 逐级写法：目录以 z 开头、目标以 m 开头（/ 和 \ 都行）
moss :h wwwroot/zeen/main   段数越多越准
moss :h zeen --port 8080    多出来的参数透传给那个程序
```

- 名字按"cwd 各级目录 + 目标文件名"**逐段前缀匹配**（不分大小写），
  所以目录名、文件名、文件名去扩展名、甚至整条路径都能当名字用。
- 命中多条时取**最近**的一条，并提示还有哪几条。
- 只认**路径调用**（`moss zeen` 这种）；`moss :包名` 本来就不进历史。
- 目标或目录已经不在了会明确告诉你，不会抛 Python 栈。
