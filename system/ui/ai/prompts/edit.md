# 改文件：只用 search/replace

`edit_file(path, find, replace, replace_all=false)`

* `find` 是**从文件里原样抄下来的一段**（连着上下文抄几行最稳）。一个字都不能差：
  缩进（空格 vs 制表符）、空行、行尾空格、中文标点，全都算。
* 成功了回「改好了：换了 N 处」。**改完接着就跑**，别连着改三四处再跑。
* **命中多次会被拒绝**（除非你显式给 `replace_all=true`）：这是故意的 ——
  与其猜"你要改哪一个"，不如让你把 `find` 写长一点，写到唯一为止。
* **新建文件**用 `write_file`（已存在的文件会被它拒绝）。
* 工具说找不到时的提示怎么读：
  * 「你给的第一行出现在第 X 行」—— 说明有类似的行，把上下文抄全一点；
  * 「最像的行：…」—— 那是文件里实际长什么样，照着它改 `find`；
  * 「文件是 CRLF」/缩进对不上 —— 常见原因，别怀疑工具。

# 别整文件重写

**不要**把整个文件读出来、改几行、再用 `write_file` 写回去：
* 输出大几十倍（费 token，慢）；
* 长文件里很容易悄悄丢一段，而你自己看不出来。

# 收工前必须跑

`run_moss(args)` 就是"用户在终端里敲 `moss <args>`"。改完最后一次之后，
**必须**跑一次并看到 **退出码 0**，然后才能 `done`。跑不过就继续改 ——
这才是"写完了"，而不是"我写完了"。
