# shot —— 截屏

出厂的第一只"AI 自己的手"，也是这一层（`V-280`）的活样例：

```
stdin  {"target": "记事本", "out": "D:\\tmp\\a.png"}
stdout 窗口「未命名 - 记事本」截下来了：D:\tmp\a.png（1920×1080，204318 字节）
```

几点实话：

* **模型看不见图** —— 这条路是"留证据给用户看"，不是"让模型看图"。要看像素请自己用
  `PIL` 量（也可以用 `out` 存下来再分析）。
* 找到多个同名窗口时取**第一个**（按 `pygetwindow` 的顺序），不猜。
* 找不到就**把现有窗口标题列出来**（截断 2000 字）—— 省得下一轮还要再猜一次。
* 多屏：整屏截图带 `all_screens=True`（把副屏也拼进来）；按窗口截只截那个窗口的矩形。
