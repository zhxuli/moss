# 写一个新包：照这个顺序走（每一步都别跳）

1. `list_dir` 看一眼 `user_data/pkgs/`（有没有重名）。
2. **读契约**（读一次就够，别反复读）：
   * `spec("pkg.json")` —— 字段表 + `params`（含 `rest`）+ `drop` 声明；
   * 要**界面**就再 `spec("界面")`（`ui.embed` + 垫片那套）；
   * 要**能收拖入**就必须 `spec("拖放")` —— 那张六道关的表，漏一道的症状
     就是"拖进来没反应 / 提示不消失"。
3. 骨架优先：`run_moss("--new <id>")` 能生成一个能跑的包（`pkg.json` + `run.py` + `AGENT.md`），
   比从零写稳。要界面就照 `system/pkgs/bmi/` 抄（`main.py` 两种模式 + `ui/` 三个文件）。
4. 改完 → `run_moss(":<id> <示例参数>")` → **退出码 0** → 再 `done`。
5. `done` 里写：包 id、文件清单、验收用的那条命令 + 它的结果、以及没验到的部分。

**别忘的几条**（都是踩过的）：
* `id` 只能小写字母开头、`[a-z0-9_-]`、≤32 字符；
* `drop` 声明必须和代码事实一致（`ext` 收哪些格式 = 代码真能处理哪些）；
* 数据写 `MOSS_PLUGIN_DATA_DIR`，别写包目录；
* 参数从 `MOSS_PKG_PARAMS`（JSON）读，别人肉切 `sys.argv`；
* 实测：`moss :<id>` 和带参数两种用法都要能跑（这是"一个包两种用法"的约定）。
