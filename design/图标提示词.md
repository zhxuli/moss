# moss 图标 —— 生成提示词

> 目标：一个 Windows 应用图标（`.ico`）。
> **唯一的验收标准是：缩到 16×16 像素还认得出。** 做不到就换一张。

---

## 硬性要求（先记住这几条）

| 要求 | 为什么 |
|---|---|
| **正方形，1024×1024** | 后面要转成 16/24/32/48/64/128/256 多尺寸 |
| **形状要粗、要少** | 16×16 只有 256 个像素，细线条和细节会糊成一团 |
| **只用 2-3 个颜色** | 颜色一多，小尺寸就变泥 |
| **不要文字** | 小到看不清，还占地方 |
| **背景用实心圆角方块，不要透明** | 透明底在深色任务栏上，深绿的苔藓会消失 |
| **不要写实照片风格** | 照片缩到 16px 就是一块脏点点 |

---

## 提示词（英文更容易出好结果，四选一）

### A · 苔藓团（我最推荐）

稳、耐缩小、含义直接。

```
Minimal flat vector app icon, square 1:1. A soft cluster of moss: 3 to 5 rounded,
slightly overlapping pebble-like blobs in graduated greens, centered, growing
gently upward. Deep forest green #2E7D4F and fresh moss green #7FBF6A on a warm
off-white #F5F1E8 rounded-square tile. Thick bold shapes, no outlines, no text,
no gradients. Generous padding around the mark. Crisp, geometric, modern
developer-tool aesthetic.
```

### B · 沿边缘生长（最贴合这个产品的语义）

呼应"贴着屏幕边缘、静静长起来"。

```
Minimal flat vector app icon, square 1:1. Moss growing along the bottom-left
inner edge of a rounded square, small rounded green clusters spilling slightly
inward and upward. Suggests something that quietly grows on the edge and stays
there. Deep green #2E7D4F moss with one accent of bright moss green #7FBF6A,
on soft off-white #F5F1E8. Very few shapes, bold, high contrast, no text,
no outlines, no gradients.
```

### C · 苔藓长成的字母 M

名字感强，但字母在小尺寸下比纯图形难认一点。

```
Minimal flat vector app icon, square 1:1. The capital letter M formed from
rounded moss blobs, as if a moss colony grew into the shape of the letter M.
Two greens only, thick soft-edged shapes, no outline, centered on a deep
charcoal #1C2321 rounded-square tile. Modern developer tool icon, geometric,
high contrast, must stay legible when tiny.
```

### D · 极简单色（最耐缩小，最保守）

```
Ultra-minimal single-color app icon, square 1:1. One abstract moss cushion:
a low rounded dome with three small bumps on top, solid deep green #2E7D4F on
an off-white #F5F1E8 rounded-square tile. Pure silhouette, no interior detail,
no gradients, no outline, no text. Designed to stay readable at 16x16 pixels.
```

## 生成之后（三步）

### 1. 缩到 16×16 看一眼

**这是唯一的验收标准。** 认不出是什么就重生成，别将就。

### 2. 转成多尺寸 `.ico`

用 moss 自带的 runtime（里面有 Pillow 11.3），不需要你另外装东西：

```powershell
D:\python\two\moss\system\runtimes\python\3.12\python.exe -c "from PIL import Image; im=Image.open(r'D:\下载\moss_icon.png').convert('RGBA'); im.save(r'D:\python\two\moss\icon.ico', sizes=[(16,16),(24,24),(32,32),(48,48),(64,64),(128,128),(256,256)]); print('已生成 icon.ico')"
```

### 3. 验证它真的含多尺寸

```powershell
D:\python\two\moss\system\runtimes\python\3.12\python.exe -c "from PIL import Image; im=Image.open(r'D:\python\two\moss\icon.ico'); print('主尺寸', im.size); print('内含', sorted(im.info.get('sizes', [])))"
```

应当看到 7 个尺寸，最大 256×256。

## 配色备忘

| 用途 | 色值 |
|---|---|
| 深苔绿（主） | `#2E7D4F` |
| 嫩苔绿（点缀） | `#7FBF6A` |
| 暖白底 | `#F5F1E8` |
| 深炭底（深色版用） | `#1C2321` |

想要深色版就把底色换成 `#1C2321`、苔藓换成亮一点的绿（`#7FBF6A` / `#A8D98A`）。
**别用中间调的灰绿** —— 小尺寸下和背景糊在一起。
